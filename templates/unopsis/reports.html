The difference between this page and /insights/ is who it is for. /insights/ is a working surface -- you search it, you POST to it, you narrow it down. This page answers one question instead: "what does the database say right now, and can I take it with me?" So it carries no forms, only 1. one TOTALS line, from .count() / .aggregate(); 2. several GROUPED summaries, from .values(...).annotate(Count(...)) -- Django's GROUP BY; 3. the two export buttons, which are the only clickable way to get a file out of the project. Both links are {% templatetag openblock %} url 'export-items-csv' {% templatetag closeblock %} style lookups, so the download addresses live in unopsis/urls.py like every other one. Every table below has real headers and an {% templatetag openblock %} empty {% templatetag closeblock %} branch, because a report that silently shows nothing on an empty database is indistinguishable from a report that is broken. The numbers come from the same aggregate_summaries() helper /insights/ uses, so the two pages can never disagree about how many items are in a lane. {% endcomment %} {% block title %}Reports & exports{% endblock %} {% block content %}
